# OpenCode Skill Generator

Generador estructurado de habilidades multi-archivo para OpenCode CLI.

## Overview

Esta skill estandariza la creación de nuevas herramientas o contextos para el CLI, asegurando una arquitectura modular, segura y optimizada.

## Usage

Úsala cuando necesites crear una nueva skill desde cero. El agente te hará una entrevista de 6 pasos antes de generar el código.

## File Structure

```
opencode-skill-generator/
├── SKILL.md
├── metadata.json
└── README.md

```

## Key Principles

1. **Entrevista obligatoria** antes de generar código.

2. **Arquitectura multi-archivo** por defecto.

3. **Definición estricta** de permisos, alcance y limpieza de contexto.
