# Conventional Commits

Formato: `<tipo>[ámbito opcional][!]: <descripción>`

## Tipos
`feat` `fix` `refactor` `perf` `docs` `test` `chore` `build` `ci` `style` `revert`

## Breaking changes
- Añadir `!` tras el tipo/ámbito: `feat(api)!: ...`
- Y un footer obligatorio: `BREAKING CHANGE: <explicación y migración>`

## Footer
- Issues/PRs: `Closes #42`, `Refs #17`
- Co-autoría: `Co-authored-by: Nombre <email>`

Referencia: https://www.conventionalcommits.org
